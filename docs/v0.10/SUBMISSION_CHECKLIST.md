# Submission checklist

## Product / demo
- [ ] End-to-end demo runs from a clean install.
- [ ] At least one real Meta model call is captured and reproducible, if API access is available.
- [ ] Local fallback is clearly labelled and not presented as Meta output.
- [ ] Existing 30-case golden set has a measured evaluation report.
- [ ] Exact source quote is visible beside extracted fields.
- [ ] Missing/estimated fields and blockers are visible.
- [ ] Human approval is explicit.
- [ ] Simulated data/outcome label remains visible.

## Repository
- [ ] Public repository URL verified.
- [ ] README includes setup, architecture, model usage, limitations and attribution.
- [ ] Hackathon-built features are clearly identified.
- [ ] No API keys, personal data or secrets committed.
- [ ] License and third-party assets/code rights reviewed.
- [ ] Tests/build pass from clean install.

## 3-minute video
- [ ] 0:00–0:20 problem: coordination is fragmented; infrastructure already exists.
- [ ] 0:20–0:55 message → structured draft + exact evidence.
- [ ] 0:55–1:20 missing fields / uncertainty / clarification.
- [ ] 1:20–2:05 feasible proposal + blocked alternatives with reason codes.
- [ ] 2:05–2:35 explicit human decision + audit trail.
- [ ] 2:35–3:00 why Meta model + why agent-first coordination layer.
- [ ] No claim of real deliveries, beneficiaries, saved food or emissions unless measured.

## Logistics
- [ ] Confirm official submission deadline/timezone from the event page.
- [ ] Confirm submission form, video URL permissions, and public repo visibility.
- [ ] Submit with time buffer and verify confirmation.
