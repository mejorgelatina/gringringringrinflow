# Demo script — target 3 minutes

## 0:00–0:20 — Problem
“Food rescue doesn’t lack infrastructure. It has donors, community kitchens, food banks, vehicles and people coordinating through messages, calls and spreadsheets. What’s missing is a shared intelligence layer that can see the constraints together.”

## 0:20–0:55 — Intake
Paste: “Tenemos 20 cajas de pan fresco en la colonia Roma, hay que recogerlas antes de las 6 pm.”
“GrinFlow turns an informal message into a structured draft. We keep the exact source quote visible, and separate what was stated from what remains unknown. In this run, the extraction provider is [say the actual provider shown in the UI].”

## 0:55–1:20 — Uncertainty
“An AI guess is not ground truth. If quantity, condition, deadline or location is missing—or the quantity is only an estimate—the system asks for clarification or blocks the proposal.”

## 1:20–2:05 — Coordination
“The model does not decide where the food goes. A deterministic engine checks category, condition, receiving window, quantity and confirmed transport capacity. One option may be feasible; other options show exactly why they are blocked. A score cannot override a hard constraint.”

## 2:05–2:35 — Human decision and trace
“The operator must explicitly approve or reject. That records a decision; it does not dispatch a driver. The audit trail separates proposal, approval and execution.”

## 2:35–3:00 — Why this matters / Meta
“GrinFlow doesn’t replace the infrastructure people already use. It coordinates it. We’re using Meta’s model for interpreting informal language, with deterministic rules and human authorization around consequential decisions. All data and outcomes in this demo are synthetic.”

**Recording note:** Only say “Meta’s model” if the UI confirms a live Meta Model API call during the recorded run. If using local fallback, disclose it and do not imply the fallback is a Meta model.
